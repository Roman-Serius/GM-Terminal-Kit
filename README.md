# GM Terminal Kit

Build fake retro computers for your tabletop game, or make a whole terminal game.

GM Terminal Kit is a single HTML file. You build a computer (files, folders, passwords, mail, programs, events), switch to Player mode and turn the screen around. No install, no account, no code. It runs in your browser, even offline.

**Get it on itch.io (pay what you want, including free):**
https://roman-serius.itch.io/gm-terminal-kit-thornfield-demo

## What's here

- `GM Terminal Kit/`: the kit itself, the GM guide and the README
- `Test scenarios/showcase.json`: Kestrel Station, the sample game built into the kit

## Try it

Open `GM Terminal Kit/GM Terminal.html` in Chrome, Safari or Firefox, then click "Load the sample scenario".
